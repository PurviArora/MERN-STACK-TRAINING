                         Day-19-MongoDB


Introduction
Mongo DB is a Document-Oriented, No SQL database created in C++
Unstructured database
No SQL stands for "Not Only SQL"
No SQL stores data in flexible formats such as :- Document, Key-Value, Graph, Column-based




SQL : Tables, Rows, Columns, Fixed Schema, MySQL
No SQL : Collection, Documents, Fields, Flexible Schema, MongoDB

Comparison Operators
Equal to {<key>:{$eg;<value>}}
Less Than {<key>:{$lt:<value>}}
Less than equal {<key>:{$lte:<value>}}
Greater Than : {<key>:{$gt:<value>}}
Greater Than or equal {<key>:{$gte:<value>}}
Not Equal {<key>:{$ne:<value>}}
Values in an array {<key>:{$in:[<value1>, <value2>,<valueN>]}}
Values not in an array {<key>:{$nin:<value>}}


12. AND in MongoDB
db.mycol.find({ $and: [ {<key1>:<value1>}, { <key2>:<value2>} ] })

13. OR in MongoDB
db.mycol.find({$or: [{key1: value1}, {key2:value2}]}).pretty()

14. NOT in MongoDB
db.COLLECTION_NAME.find({$not: [{key1: value1}, {key2:value2}]})
